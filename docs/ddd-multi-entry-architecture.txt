╚══════════════════════════════════════════════════════════════════════╝

  DDD 的核心目的
  ─────────────
  讓程式碼說「業務的語言」，而不是「技術的語言」。
  業務邏輯集中在一處，技術細節（HTTP / DB / Kafka / Lambda）向外推。
  清楚的邊界讓每個模組可以獨立替換、部署、甚至擴展到不同運算環境。

╔══════════════════════════════════════════════════════════════════════╗
║  各入口方案細節                                                        ║
╚══════════════════════════════════════════════════════════════════════╝

  ┌─────────────────────────────────────────────────────────────────┐
  │  REST API  (cclemon-web, port 8888)              ✅ 已支援       │
  ├─────────────────────────────────────────────────────────────────┤
  │  WeightController                                                │
  │    - 職責：HTTP 協議轉換，無業務邏輯                               │
  │    - 注入 WeightHandler 介面                                     │
  │    - 建立 Command / Query DTO → 呼叫 Handler → 回傳結果           │
  │                                                                  │
  │  build.gradle:                                                   │
  │    implementation project(":cclemon-api")    // 編譯期依賴介面     │
  │    runtimeOnly   project(":cclemon-health")  // 執行期注入實作     │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │  排程 Job  (cclemon-job)                         ✅ 已支援       │
  ├─────────────────────────────────────────────────────────────────┤
  │  Job 直接注入 WeightHandler，不需要 HTTP                          │
  │  例：每日統計任務直接呼叫 handler.list(query)                      │
  │                                                                  │
  │  build.gradle:                                                   │
  │    implementation project(":cclemon-api")                        │
  │    runtimeOnly   project(":cclemon-health")                      │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │  Kafka Consumer  (cclemon-consumer)              ✅ 已支援       │
  ├─────────────────────────────────────────────────────────────────┤
  │  KafkaListenerDispatcherImpl                                     │
  │    - 根據 topic 分發至對應的 KafkaMessageHandler 實作              │
  │    - ApiLogHandlerImpl 負責處理 CCLEMON_HEALTH_API_LOG topic      │
  │                                                                  │
  │  擴展方式：實作 KafkaMessageHandler，宣告對應 topic 即可            │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │  AWS Lambda  (未來: cclemon-lambda)              🔧 需新增模組   │
  ├─────────────────────────────────────────────────────────────────┤
  │  使用 Spring Cloud Function Adapter                               │
  │                                                                  │
  │  @Bean                                                           │
  │  Function<RecordWeightCommand, WeightRecordResult> recordWeight( │
  │      WeightHandler handler) {                                    │
  │    return handler::record;   // Handler 介面完全不動              │
  │  }                                                               │
  │                                                                  │
  │  build.gradle:                                                   │
  │    implementation project(":cclemon-api")                        │
  │    runtimeOnly   project(":cclemon-health")                      │
  │    implementation 'org.springframework.cloud:                    │
  │                    spring-cloud-function-adapter-aws'            │
  │                                                                  │
  │  冷啟動優化選項：                                                  │
  │    - Provisioned Concurrency (AWS 端設定)                        │
  │    - GraalVM Native Image (啟動 < 100ms，build 時間較長)          │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │  Cloudflare Workers                              ⚠️  不直接支援  │
  ├─────────────────────────────────────────────────────────────────┤
  │  Workers 只支援 JavaScript / TypeScript / WASM                   │
  │  Java 無法直接部署                                                │
  │                                                                  │
  │  建議作法：                                                       │
  │    Workers ──HTTP──→ cclemon-web REST API                        │
  │    Workers 負責 edge 路由 / 認證 / 快取                            │
  │    業務邏輯仍在 cclemon-health                                    │
  └─────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════╗
║  設計原則摘要                                                          ║
╚══════════════════════════════════════════════════════════════════════╝

  1. Handler 介面 = Port
       任何入口都只依賴介面，不依賴 Spring / JPA / 任何框架

  2. 新增入口 = 新增 Adapter 模組
       業務邏輯（cclemon-health）完全不動
       只需新建一個模組，注入 Handler 介面

  3. runtimeOnly 依賴策略
       編譯期：看不到實作，強制依賴介面
       執行期：Spring 自動注入實作 Bean

  4. 測試邊界清晰
       Handler 層：MockitoExtension，mock Service
       Web 層：MockMvc，mock Handler
       Lambda 層：直接測試 Function<Command, Result>
